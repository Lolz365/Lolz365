## How I Work

- **Enterprise first:** WalkMe-style digital adoption, SAP learning flows, ERP data that refuses to be tidy.
- **Agents with receipts:** RAG, knowledge graphs, n8n, local models. If it cannot be inspected, it does not ship.
- **Interfaces that behave:** Semantic HTML, keyboard paths, reduced motion, and type that does not shout.
- **Tools I actually use:** Python, TypeScript, SQL, React, Docker, Linux, Cursor, GitHub.
